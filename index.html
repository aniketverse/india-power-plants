Scope: Electricity-generating stations only. Industrial establishments and their in-house generation records (including cement, steel, mining, metals, chemicals, refining, fertiliser, paper, sugar, textiles, manufacturing, ports and similar industrial sites) are excluded using a strict plant-name AND owner-name screening rule. No industrial-name exception is allowed. The underlying WRI GPPD v1.3.0 source is historical and no longer maintained, so this is a cleaned historical inventory—not a certified current register. Cross-check current plant layers against the official ISRO–NITI Energy Map and CEA generator registry. Rooftop/distributed solar is excluded.

Data notes

  • WRI GPPD v1.3.0 is historical and no longer maintained.
  • Generation history in the source is mainly 2013–2019; it is not FY 2024–25 generation.
  • Missing coordinates prevent state assignment and map display.
  • Industrial-sector records are excluded whether the sector appears in the plant name or owner name; no exception is made for CPP/captive/co-generation wording.
  • Excluded industrial records: calculated on load. Category breakdown:
    • Calculated when data loads.
  • Renewable projects are represented as individual records where present; the live VEDAS map also provides district-level renewable counts.
Official cross-check: ISRO–NITI Energy Map provides separate conventional and renewable plant layers; CEA's National Data Registry lists generating units by project, unit, fuel, state and status. These official sources are linked below for reconciliation. Their records can include industrial captive generators, so sector screening is still applied here.

Sources

1. ListBase India Power Plants download page — 1,589 records advertised; data source WRI GPPD v1.3.0; CSV served from its CDN.
2. WRI Global Power Plant Database — fields include plant name, fuel, capacity, coordinates, owner, source and historical generation; WRI says the database is not currently maintained.
3. ISRO–NITI Aayog Geospatial Energy Map of India — conventional plant layers, renewable project layers and state-wise search.
4. CEA National Data Registry for Generating Units — project/unit/fuel/state/status register; includes captive units, which are removed here when linked to industrial owners or sites.
5. CEA Generation Reports — station-wise generation reports.
